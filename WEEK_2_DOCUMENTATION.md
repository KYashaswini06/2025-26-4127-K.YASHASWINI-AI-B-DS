# Week 2 Documentation

## Pandas Operations
1. **Reading Data**: Loading data using `pandas.read_csv()`
2. **Data Inspection**: Using `.head()`, `.info()` and `.describe()` to explore data.
3. **Data Cleaning**: Handling missing values with `.dropna()` and `.fillna()`.
4. **Data Manipulation**: Filtering data, grouping, and aggregation operations.

## Sorting Algorithms
1. **Bubble Sort**: A simple comparison-based sorting algorithm.
   - **Complexity**: O(n^2)
2. **Quick Sort**: An efficient divide-and-conquer sorting algorithm.
   - **Complexity**: O(n log n)

## Searching Algorithms
1. **Linear Search**: A basic search algorithm checking each element.
   - **Complexity**: O(n)
2. **Binary Search**: An efficient search algorithm for sorted arrays.
   - **Complexity**: O(log n)

## Data Visualization
1. **Matplotlib**: Plotting data using line plots, bar charts, histograms, etc.
2. **Seaborn**: Enhancing visualizations for statistical data with aesthetics.
3. **Plotly**: Creating interactive plots for better insights.

### Conclusion
This document covers the key operations in pandas, algorithms for sorting and searching, and tools for data visualization. These are fundamental in data analysis and machine learning workflows.
